# MOTION

**MOTION** is a customizable live wallpaper application for Linux and Android, developed by flekiii.

## Downloads

Download builds from the [GitHub Releases page](https://github.com/flekiii/motion/releases).

### Linux — 0.1.0 Beta

The [Linux beta](https://github.com/flekiii/motion/releases/tag/v0.1.0-beta) is available as an AppImage and a TAR.GZ archive.

- Target: Linux x86_64, XFCE on X11.
- Uses `mpv` and `xwinwrap` for live video wallpapers; system dependencies may be required.
- Includes optional movable desktop shortcuts.

### Android — public beta in preparation

Android beta builds will be distributed as APK assets in a separate Android release. Current functionality being evaluated includes:

- Video live wallpapers for the home screen.
- Video selection and individual Home / Lock previews inside the app.
- Android's system wallpaper picker.
- Battery-aware pausing and reset controls.

**Known limitations:** Separate live wallpapers for the lock screen depend on Android device and manufacturer support (including HyperOS); the system picker may offer only Home or Home + Lock. Video playback may stutter on some devices or emulators. Android builds are beta software; do not assume all features work on every phone.

## Report bugs or suggest features

Found a bug? Please [open an issue](https://github.com/flekiii/motion/issues/new/choose). Include your Android version, device model, MOTION version, what happened, and steps to reproduce it.

Do **not** upload passwords, private video files, personal identifiers, or logs containing private information.
